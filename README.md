# Mathematical Modelling of Population Dynamics Using Differential Equations

This repository contains numerical simulation workflows, dynamical stability analyses, and phase-space bifurcation studies developed as part of my Master's thesis in Physics at Central University of Rajasthan (CURAJ).

## Repository Overview & Notebooks

- **`LOTKA VOLTERA MODEL.ipynb`**: Numerical integration of non-linear coupled predator-prey differential equations and trajectory simulations.
- **`Bifurcation due to constant harvesting in lgm.ipynb`**: Modeling logistic growth models (LGM) under continuous harvesting and stability boundary shifts.
- **`bifurcation diagrams.ipynb`**: Automated parameter sweeps visualizing saddle-node, transcritical, and pitchfork bifurcations.
- **`lgm and ae solutions.ipynb`**: Analytical and numerical solutions comparing baseline logistic growth and Allee effect (AE) dynamics.
- **`lgm & ae aly plots .ipynb`**: Phase portraits, direction fields, and state trajectory visualizations using Matplotlib.

## Computational Stack
- **Language**: Python 3.x
- **Libraries**: NumPy, SciPy (`scipy.integrate.odeint`), Matplotlib, Pandas
- **Environment**: Jupyter Notebook
